Visual Working Memory

Colored squares flash, disappear, then one location is tested. Say whether the color there is the same or different. Six practice trials come before the 36-trial main block, or you can skip practice.

What it shows

The sample is 4, 6, or 8 squares. Half of the trials keep the probed color. Half change it. The results screen reports accuracy and mean response time, then hit rate, false-alarm rate, Cowan's K, and Pashler's K for each set size.

On that screen a different trial is the signal. A hit is answering different on a different trial. A false alarm is answering different on a same trial. Cowan's K is N × (hit rate − false-alarm rate), floored at 0. Pashler's K is N × (hit rate − false-alarm rate) / (1 − false-alarm rate), kept between 0 and N. The headline K is the mean of the three Cowan values. These are teaching readouts, not a clinical capacity score.

Parameters

Practice
6 trials. One same and one different trial at each set size, then a shuffle. Skip to Main drops any practice log and starts the 36.
Main block
36 trials. Six same and six different trials at each of set sizes 4, 6, and 8, then a shuffle.
Squares
Side length 38 on a 420-unit canvas, kept 52 units from the edge, at least 68 apart, and at least 46 from the center cross. Colors are drawn from eight fixed swatches: #F94144, #38BDF8, #10B981, #F59E0B, #EC4899, #F8FAFC, #A855F7, and #A3E635. A change uses a color that was not in the sample.
Fixation
500 ms.
Sample
250 ms. Remember the colors and locations.
Delay
900 ms. The cross remains. The squares are gone.
Probe
Stays until you answer. There is no deadline. Single mode shows only the tested square, circled. Full-array mode shows every square again and circles the tested one. The welcome menu sets the mode. The header control can switch it. The default is single.
Between trials
500 ms after the choice.
Response time
Milliseconds from probe onset. The mean on the results screen includes incorrect choices.

Classical presentation

The welcome and results screens have a Gamified | Classical control. The choice is stored in this browser as project-trial:mode. ?mode=classical still opens the lab shell.

Luck and Vogel (1997), doi:10.1038/36846, measured change detection with brief colored squares. Classical uses that display: plain squares on mid-gray, then a probe. Set sizes, timings, and the same/different response stay as listed above. The sky-blue cue ring is a black ring in this shell. This is not a claim that every count matches the 1997 experiments.

How to play

  • Keep looking at the center cross. When the probe appears, decide whether that location changed color.
  • Same pad, A, or Left Arrow means same. Different pad, L, or Right Arrow means different.
  • A held key does not answer again. Pads are off until the probe is on screen.

Data

When the main block finishes, this browser stores one payload under the localStorage key projectTrial_vwm_v1. A later finished run replaces that payload. Nothing is uploaded. There is no Clear saved control.

Download CSV writes the current run, practice and main. Columns are trial, block, set_size, trial_type, response (SAME or DIFFERENT), correct, rt_ms, and timestamp. The file name is vWM_change_detection_ plus a timestamp. The saved payload also keeps the summary and the probe mode at the end of the run. Those are not CSV columns. The page does not log orientation turns.
