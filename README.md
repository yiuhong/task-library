# Project Trial

Gamified cognitive and behavioral tasks you can run in the browser.

Public hub: [https://yiuhong.github.io/task-library/](https://yiuhong.github.io/task-library/)

Project Trial is Yiu Hong Ko’s browser collection of attention, perception, and reaction-time tasks. The GitHub repository stays named `task-library`.

## Wordmark

Locked take B, traced as vectors in `assets/`:

- [`assets/project-trial-wordmark.svg`](assets/project-trial-wordmark.svg) — black on transparent. This is the black-and-white sibling mark for the personal site.
- [`assets/project-trial-wordmark-dark.svg`](assets/project-trial-wordmark-dark.svg) — white type and cyan instruments on transparent. This is the mark on the dark hub.

Thin “Project”, bold “Trial”: a reticle on the i, a keyboard key for the a, and a vertical reaction-time scale for the l.

## Live on the hub

- **Stroop Dash** — [`stroop_game.html`](stroop_game.html). Selective attention and Stroop interference.
- **Oddball** — [`oddball_game.html`](oddball_game.html). Rare-target detection among frequent standards.
- **Brightness Detection** — [`brightness_game.html`](brightness_game.html). Luminance discrimination with confidence ratings.
