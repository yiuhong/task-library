The rule on this page

These are conservative rules of thumb for a browser tab, not a lab certificate. The same thresholds are written into the JSON.

  • Pass if the median performance.now() step is 1 ms or less.
  • Fail if the median step is coarser than 1 ms, or if the clock did not move in the sample loop.
  • Could not run if this tab was hidden, or if the browser has no performance.now(). That is not a machine fail.

The loop records up to 20 changes. Pass is a check icon and the word Pass. Fail is a cross icon and the word Fail. Could not run is a dash icon and those words.

Interpretation

performance.now() is a monotonic page clock. Its origin is this page load. A small step is not proof that a stimulus lasted that many milliseconds on screen. Stimulus timing is still limited by the display and by setTimeout.

navigator.deviceMemory, when the browser sends it, is a coarse bucket, often capped. The CPU value is a hint. The storage line is a one-key probe: the page writes project-trial:device-check-probe, reads it back, and removes it. Verdicts are not stored. Trial rows are not stored here.

What this page can and cannot stand behind

  • performance.now() is a monotonic page clock. Its origin is this page load. A small step is not proof that a stimulus lasted that many milliseconds on screen.
  • A background tab, a busy processor, or a low-power setting can move other timers on this site. Repeat the check on the machine and the browser you will actually use.
  • The download is a JSON file you choose to save. This site does not receive it. The check does not open a task, does not score a person, and does not ask for consent because it is not a study.
