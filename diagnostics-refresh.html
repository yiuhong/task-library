The rule on this page

These are conservative rules of thumb for a browser tab, not a lab certificate. The same thresholds are written into the JSON.

  • Pass if this tab stayed visible and the estimated rate is within ±5 Hz of a common rate: 50, 60, 75, 90, 120, 144, or 165 Hz.
  • Fail if the estimate completed and is not within ±5 Hz of one of those rates. An estimated rate below 45 Hz fails.
  • Could not run if this tab was hidden during the sample, or if the browser has no requestAnimationFrame. The hidden-tab sample is discarded. Could not run is not a machine fail.

The sample asks for 120 animation frames. The first 5 intervals are left out. Pass is a check icon and the word Pass. Fail is a cross icon and the word Fail. Could not run is a dash icon and those words.

navigator.deviceMemory, when the browser sends it, is a coarse bucket, often capped. The CPU value is a hint. The storage line is a one-key probe: the page writes project-trial:device-check-probe, reads it back, and removes it. Verdicts are not stored. Trial rows are not stored here.

What this page can and cannot stand behind

  • The refresh estimate is how often requestAnimationFrame ran while this tab was visible. It can be lower than the rate printed on the monitor. It is not when the pixels changed. A light sensor on the glass would be required to time the pixels. This page does not use one.
  • A background tab, a busy processor, or a low-power setting can move this number. Repeat the check on the machine and the browser you will actually use.
  • The download is a JSON file you choose to save. This site does not receive it. The check does not open a task, does not score a person, and does not ask for consent because it is not a study.
