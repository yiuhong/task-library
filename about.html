How to respond

Each demo has large pads and a matching key. A tap and a keypress call the same response path. One response counts per trial. Holding a key does not fire the next trial.

Data

Nothing is uploaded. Stroop Dash, Oddball Dash, and Brightness Detection each keep their runs in localStorage on this browser and can download a CSV of those trials, including orientation start and turn rows. Clear saved removes that browser copy. Refresh does not.

Portrait and landscape both run. Hub demos do not lock orientation. Each saved trial includes the orientation at that moment, and turns during the run are timestamped on the session log. See each task’s parameters page for where that log lives.

Scores are for teaching. They are not a clinical assessment.

Look and future demos

Shared colors, type, pad chrome, and HUD spacing live in assets/trial-theme.css. A new demo can link that file and override the variables it cares about. The helpers are optional, so a demo can still invent its own controls and stimulus layout.
