Device check

A reading of this browser on this computer. It estimates the animation callback, the lateness of setTimeout, and the page clock from a color change to a key or a click. It is a support step before you run a task. It is not a validation, and it does not collect a study.

What you can learn here

Run it with this tab in front of you. A hidden tab will slow the timers, and a refresh sample taken in the background is discarded. The numbers describe this moment. Run it again on each machine you care about, and download the JSON if you want to keep it. The file stays on this computer.

Response clock

Five flashes. Each one waits about half a second to nine tenths of a second, then the square turns light on the next animation frame. Press any key, or click the square. The page clock is the time from that frame’s callback to the input handler. It includes your movement. It leaves out the display lag and most of the device lag. Use it to see that the pipeline on this machine returns a number. Do not enter it as a participant’s reaction time.

What this page can and cannot stand behind

  • The refresh estimate is how often requestAnimationFrame ran while this tab was visible. It can be lower than the rate printed on the monitor. A light sensor on the glass would be required to time the pixels. This page does not use one.
  • setTimeout is the timer the tasks use for fixation, stimuli, and the gap between trials. The check reports how late those callbacks were compared with the delay this page asked for. The callback is not a vertical-blank interrupt.
  • performance.now() is a monotonic page clock. Its origin is this page load. A small step in a tight loop does not mean a stimulus lasted that many milliseconds on screen.
  • The response-clock number ends when the input handler runs. Time in the keyboard, touchscreen, operating system, and the display is outside it. If event.timeStamp uses another origin, the handler gap is left blank.
  • A background tab, a busy processor, or a low-power setting can move every number on this page. Repeat the check on the machine and the browser you will actually use.
  • The download is a JSON file you choose to save. This site does not receive it. The check does not open a task, does not score a person, and does not ask for consent because it is not a study.
