# Contributing

New tasks follow [Package conventions](docs/package-conventions.md).

Hub tasks on the shared shells also follow [assets/SHELL_CONTRACT.md](assets/SHELL_CONTRACT.md). A scored task also follows [docs/rigor-standard.md](docs/rigor-standard.md). A task that adds a trial download loads [assets/trial-export.js](assets/trial-export.js), as described there. Visual working memory, numerosity comparison, and Eriksen flanker schedule brief intervals with [assets/trial-timing.js](assets/trial-timing.js).

How to cite the library, and what the licenses allow, is on [Cite & reuse](cite.html). The license table is also on [Licenses](license.html). Teaching content is CC BY 4.0 ([LICENSE](LICENSE)). Source code is MIT ([LICENSE-CODE](LICENSE-CODE)). Release notes are in [CHANGELOG.md](CHANGELOG.md).

Bugs and ideas go to [GitHub Issues](https://github.com/yiuhong/task-library/issues). A pull request is welcome. It is not a guarantee of merge.
