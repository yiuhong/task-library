# Changelog

Version numbers for Project Trial start at 0.1.0. There is no earlier release and no prior version tag.

## Unreleased

- Added a headset Device check (`diagnostics-headset.html`) for Spatial Go/No-Go. It reports whether `navigator.xr` is present, whether `immersive-vr` is offered, whether a session can start and end, which reference spaces are available, and which input sources were seen. Pass needs a session that starts and ends with `local-floor`. A missing WebXR API, a desktop or phone without a headset, a hidden tab, a dismissed prompt, or a stopped run is could not run. Seeing no controller does not fail the check. The JSON schema stays `project-trial.device-check.v2` because the file envelope is unchanged. The Spatial Go/No-Go start sheet has an Enter VR control that calls the scene’s existing session, and the page no longer says it was tested on VIVE Focus 3. The public version stays 0.1.0.
- The hub landing on `index.html` shows a Device check card under the feature list. It links to `diagnostics.html`. The card stays on the landing view, separate from the area tiles and from the task cards inside an area. The public version stays 0.1.0.
- The hub hero on `index.html` lists three features in the existing bold face: Teaching, Trying out experiments, and Keeping people engaged. A quieter line under the list keeps the two-shell note and the lines about playing in the browser and responses staying on this device. On a short desktop orbit the block tightens so it stays off the area tiles. The public version stays 0.1.0.
- Added For researchers (`researchers.html`) and a device check. `diagnostics.html` is a hub. The checks are separate pages: refresh (`diagnostics-refresh.html`), `setTimeout` lateness (`diagnostics-timers.html`), the `performance.now()` step (`diagnostics-clock.html`), and the page clock from a color change to a key or a click (`diagnostics-page-clock.html`). Each page shows a pass, fail, or could-not-run mark, the numbers, an interpretation, and a JSON download. Nothing is uploaded, and it is not a light-sensor validation. The public version stays 0.1.0.
- Visual working memory and Eriksen flanker download trial-by-trial JSON and CSV from `assets/trial-export.js` on the results screen. Both shells use the same trial loop. Flanker hides the running accuracy and mean RT header in both shells. The public version stays 0.1.0 until a later release note folds this in.
- Stroop, Oddball, Go / No-Go, Brightness, Numerosity, RDK, Corsi, and Reversal Learning use that same download. Practice rows stay in the file and are marked practice. A running score and a running mean RT stay off during a trial in both shells. Spatial Go/No-Go uses the same schema on its one WebXR scene. `?mode=classical` there turns off the floating outcome words and does not restyle the scene. `noematachograph.html` is unchanged. The public version stays 0.1.0.
