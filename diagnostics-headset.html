The rule on this page

Open this page in the browser you will use, including a headset browser.

  • Pass if this tab was visible, an immersive-vr session started and ended, and a local-floor reference space was available. Seeing no controller does not fail the check.
  • Fail if this browser reported immersive-vr support, then did not start a session after the button press, or the session started but local-floor was not available, or the session did not end cleanly. Spatial Go/No-Go requests local-floor. local alone is not enough for that scene.
  • Could not run if this browser has no WebXR API, it does not offer immersive-vr, this tab was hidden, the prompt was dismissed, or you stopped the run. A desktop or phone without a headset is could not run. That is not a machine fail.

Run this check

Leave this tab visible. Accept the prompt if this browser shows one. The headset view may go dark for a moment, then this page returns. Stop, or leaving the session early, is could not run. Escape stops the run.

Interpretation

Spatial Go/No-Go’s scene requests local-floor. A session that starts without that space fails this check. Zero input sources are reported and do not fail the check.

What this session asks for

The button press is the gesture. The session asks for local-floor, bounded-floor, and unbounded as optional features, then requests local-floor, local, viewer, bounded-floor, and unbounded. local and viewer are baseline spaces and do not have to be listed.

A missing WebGL layer is reported. It does not, by itself, change the pass or fail.

About these browser hints

navigator.deviceMemory, when the browser sends it, is a coarse bucket, often capped. The CPU value is a hint. The storage line is a one-key probe: the page writes project-trial:device-check-probe, reads it back, and removes it. Verdicts are not stored. Trial rows are not stored here.

Limits of this number
  • The check is this browser at this moment. It is not a certificate that a later session, or another browser on the same headset, will behave the same way.
  • The session is short. Controllers that connect later are not counted. Gaze-only play can show zero input sources, and that is not a fail by itself.
  • A background tab, a dismissed prompt, or a stop is could not run. Repeat the check on the browser you will actually use, with this tab visible.
  • The download is a JSON file you choose to save. This site does not receive it. The check does not open a task, does not score a person, and does not ask for consent because it is not a study.
  • It is not a study. It is not a photodiode or light-sensor validation.
