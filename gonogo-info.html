Go / No-Go

A green arrow is a go. Tap the matching side before the deadline. A red X is a no-go. Do not tap. Eight practice trials come before the 40-trial main block.

What it shows

Most trials are go trials. A smaller share are no-go trials. The results screen reports accuracy, mean go response time, commission rate, and omission rate. A commission is a tap on a no-go trial. An omission is a go trial that reaches the deadline with no tap.

On the gamified shell, a correct go shows HIT. The wrong side shows WRONG SIDE. A tap on a no-go shows FALSE ALARM. A missed go shows TOO SLOW. A withheld no-go shows WITHHELD. Classical practice shortens those words, and the classical main block shows none. See Shells. This is a teaching demo, not a clinical or normed test.

Parameters

Practice
8 trials. round(8 × 0.75) = 6 go and 2 no-go. Go sides alternate left and right before the shuffle, so 3 left and 3 right. No-go is 1 left and 1 right in the stored side field. The picture on a no-go trial is the red X, not an arrow.
Main block
40 trials. 30 go and 10 no-go. Go is 15 left and 15 right. No-go stores 5 left and 5 right. Order is a Fisher–Yates shuffle.
Fixation
400 ms. A plus sign.
Go window
700 ms. A lime arrow and a shrinking bar. The correct pad matches the arrow. A miss is an omission.
No-go window
800 ms. A coral X. The correct action is to do nothing until the window ends. A tap is a commission.
Feedback
400 ms, then a blank from 250 ms through 450 ms.
Response time
Milliseconds from stimulus onset on a tap. A withhold stores an empty time. Go mean response time uses correct go trials only.

Classical presentation

The welcome and results screens have a Gamified | Classical control. The choice is stored in this browser as project-trial:mode. ?mode=classical still opens the lab shell.

No additional go / no-go citation was verified for this shell. The go stimulus stays a green arrow and the no-go stimulus stays a red X. The glowing frame and halo around the X are removed. Trial counts, the 700 ms go window, and the left/right mapping are unchanged.

Shells

The same go / no-go core runs in two shells. Go / No-Go is the gamified shell. Classical Go / No-Go is the quiet lab shell on a mid-gray canvas. Both use one trial list: 8 practice trials and 40 main trials, with the same go rate, keys, and timings. Neither shell plays sound or keeps a score. The green GO badge, the red NO-GO mark, and the shrinking deadline bar stay on the stimulus in both shells.

The gamified shell shows HIT, WRONG SIDE, FALSE ALARM!, TOO SLOW!, or WITHHELD after every practice trial and every main trial, with the existing subtitle. Classical practice keeps a short word for the 400 ms hold only. HIT and WITHHELD become Correct. WRONG SIDE and FALSE ALARM become Incorrect. A missed go (TOO SLOW) becomes No response. It does not show the response time or the old subtitle. The classical main block writes no words. The feedback line is cleared, and the 400 ms hold and the blank from 250 ms through 450 ms still run. The end screen is the same in both shells: go accuracy, go mean response time, commission, and omission for the main block.

How to play

  • On a green arrow, tap the pad on that side, or press A or Left Arrow for left and L or Right Arrow for right.
  • On a red X, keep still until the trial ends.
  • A held key does not answer again. One tap is accepted while the stimulus is waiting.
  • Run New Session starts practice over.

Methods note

Both shells share the 8 practice trials and the 40 main trials. After the response is stored, the gamified shell shows HIT, WRONG SIDE, FALSE ALARM!, TOO SLOW!, or WITHHELD for the 400 ms hold. Classical practice uses Correct, Incorrect, or No response. Classical main shows no word. The hold and the jittered blank still run. The GO badge, the NO-GO mark, and the deadline bar stay in both shells. The header shows the block and the trial count, not a running score. For a main block without the word, use classical.

The download is the shared export on For researchers. rt_ms is blank when the window closes with no press. Practice rows are marked practice. Nothing is uploaded.

Data

When the main block finishes, this browser stores one payload under the localStorage key projectTrial_gonogo_v1. A later finished run replaces that payload. Nothing is uploaded. There is no Clear saved control.

Download CSV and Download JSON write the current run, practice and main. The JSON schema is project-trial.export.v1. The task id is gonogo. condition is GO or NOGO. Task columns are trial_in_block and target_side. summary repeats go accuracy, mean go RT, commission, and omission. File names start with projectTrial_gonogo_. The page does not log orientation turns.
