Corsi Span

Nine blocks sit on a board. A sequence flashes. After the go cue, tap the same blocks in the same order. Two warmup trials at span 3 come before the main spans.

What it shows

The main run starts at span 3 and can climb to span 9. In the default staircase, a span with at least one correct sequence of two continues. A span with none correct stops the run. Fixed mode plays both trials at every span from 3 through 9.

The summary reports the longest main span with at least one correct sequence, how many main sequences were correct, the sum of those correct span lengths, and a product of max span times the number of correct main sequences. It also reports mean tap time. This is a teaching demo, not a clinical or normed test.

Parameters

Warmup
2 trials at span 3. The sequence is a random sample of the nine blocks, with no repeats inside a trial.
Main spans
2 trials at each span, from 3 up. Staircase is the default and stops after 0 of 2 correct. Fixed mode continues through span 9.
Board
Nine blocks at fixed positions on a square board. Each block is 14.5% of the board.
Watch
650 ms before the first flash. Each block lights for 500 ms, with 250 ms between blocks. A short tone can play with each flash.
Recall
200 ms after the last flash, a go cue opens tapping. The trial submits itself when the tap count matches the span. Clear Input wipes the current taps before that. Blocks do not accept taps while the sequence is playing.
Between trials
900 ms after feedback, then the next sequence.
Sound
On at the start. The welcome menu can mute the tones. Visual flashes stay.
Tap time
Each tap is timed from the go cue. The trial stores total time and the mean time between taps.

Shells

The same Corsi core runs in two shells. Corsi Span is the gamified shell. Classical Corsi span is the quiet lab shell on a mid-gray canvas. Warmup is still 2 trials at span 3. The progression menu, staircase or fixed, stays in both shells, and the default is still the staircase. There is no live score during trials. The end screen keeps max span, correct sequences, block score (the sum of correct span lengths), the product, and mean tap time. Block score on that screen is part of the summary.

Documented exception: sequence tones and tap tones are off in the classical shell, including the go-cue tone. Flash timing is unchanged: 650 ms before the first flash, each block lit for 500 ms, 250 ms between blocks, and 200 ms before the go cue. The go cue is still shown. Gamified keeps AUDIO CUES and every current tone. Classical hides AUDIO CUES, ignores that control, and does not write the shared project-trial:sfx key. During classical practice the banner after a sequence is a brief Correct or Incorrect, with no tone. During the classical main block those banners are not shown. The 900 ms pause before the next sequence still runs, and the taps stay on the blocks until that pause ends. The gamified shell keeps the CORRECT SEQUENCE and INCORRECT SEQUENCE banners and the tones.

How to play

  • Watch the whole sequence. Wait for the go cue, then tap the blocks in order.
  • Taps use the blocks themselves. There is no letter key for a block.
  • Clear Input resets the taps on the current trial. It does not skip the trial.
  • Choose staircase or fixed before Start Practice Warmup. On the gamified shell, choose sound on or off there too. The classical shell hides that control and leaves sound off.

Data

When the main run finishes, this browser appends one session to a list under the localStorage key projectTrial_corsi_v1. Older finished runs stay in that list. Each saved session includes mode (gamified or classical). Nothing is uploaded. There is no Clear saved control.

Download CSV Log writes the current run only. Columns are trial, block, span_length, target_seq, user_seq, correct, total_rt_ms, mean_tap_rt_ms, timestamp, and mode. mode is gamified or classical and is the last column. The file name is projectTrial_corsi_span_ plus a timestamp. The page does not log orientation turns.
