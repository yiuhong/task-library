Eriksen Flanker

Report the direction of the center arrow. The arrows beside it may match, conflict, or be dashes. Six practice trials come before the 36-trial main block.

What it shows

Each trial shows a fixation cross, then a row of five symbols. The center symbol is < or >. On congruent trials the flankers point the same way. On incongruent trials they point the other way. On neutral trials the flankers are dashes. The summary compares accuracy and mean response time for those three conditions.

The gamified shell says correct, incorrect, or too slow after each trial. Classical practice uses a shorter word, and the classical main block does not. See Shells. This is a teaching demo, not a clinical or normed test.

Parameters

Practice
6 trials. One of each condition for each target direction, then a Fisher–Yates shuffle.
Main block
36 trials. Six of each condition for each target direction, then a Fisher–Yates shuffle.
Array
Flanker, flanker, target, flanker, flanker. Congruent copies the target. Incongruent uses the opposite arrow. Neutral uses -.
Fixation
A random duration from 400 ms through 600 ms. A plus sign. The choice is not open yet.
Choice window
1500 ms from stimulus onset. A timeout is incorrect, shows TOO SLOW, and stores an empty response time.
Feedback
400 ms, then a 350 ms blank.
Accuracy and mean time
Accuracy is correct trials divided by all trials in the block, so a timeout counts as incorrect. Mean response time uses correct trials only.

Classical presentation

The welcome and results screens have a Gamified | Classical control. The choice is stored in this browser as project-trial:mode. ?mode=classical still opens the lab shell.

Eriksen and Eriksen (1974), doi:10.3758/bf03203267, used a central target letter with flanking letters. This demo already uses arrows. Classical draws that same array as plain dark glyphs on gray, with the center arrow in the same ink as the flankers. Trial counts, the 1500 ms window, and the left/right mapping are unchanged.

Shells

The same flanker core runs in two shells. Eriksen Flanker is the gamified shell. Classical Flanker is the quiet lab shell on a mid-gray canvas. Both use one trial list: 6 practice trials and 36 main trials, with the same arrays, keys, and timings. Neither shell plays sound or keeps a score.

The gamified shell shows TOO SLOW, ✓ CORRECT, or ✕ INCORRECT after every practice trial and every main trial, with the response time or the target side underneath. Classical practice keeps a short word for the 400 ms hold only: Correct, Incorrect, or No response. It does not show the response time or that subtitle. The classical main block writes no words. The feedback line is cleared, and the 400 ms hold and 350 ms blank still run, so the time from one trial to the next does not change. The end screen is the same in both shells: main-block accuracy, mean correct response time, and the conflict effect. Practice is not part of those totals. The header slots for a running accuracy and a running mean RT are hidden in both shells. The trial counter and the progress bar stay.

Methods note

Both shells share one trial list, one response window, and one score. The word on the gamified shell is drawn after rt_ms is stored, during the 400 ms hold that classical also waits through. A correct gamified trial shows that response time. An error shows the target side. That cue can change the next response. It does not change the array, the key, or the conflict effect. For a main block without the word, use classical.

The download is the shared export described on For researchers. fixation_ms is the fixation that was drawn. Response time starts at the array, so fixation is outside rt_ms. A timeout leaves rt_ms blank, sets timed_out to 1, and counts as incorrect. The mean on the results screen still uses correct trials only. The conflict effect is still incongruent mean correct RT minus congruent mean correct RT. Browser timing limits, and a device check you can run on your own machine, are on For researchers and the device check. Nothing is uploaded.

How to play

  • Look at the center symbol. Choose the direction it points.
  • Left pad, A, or Left Arrow means left. Right pad, L, or Right Arrow means right. A pad press and a key call the same choice.
  • A held key does not answer again. One choice is accepted while the arrows are waiting for a response.
  • Run Again starts practice over and clears the on-screen log for the new run.

Data

When the main block finishes, this browser stores one payload under the localStorage key projectTrial_flanker_v1. A later finished run replaces that payload. Nothing is uploaded. There is no Clear saved control.

Download Trial CSV and Download Trial JSON write the current run, practice and main, when you press the button. The JSON schema is project-trial.export.v1. It carries the task id flanker, the mode, a parameter snapshot, the results-screen summary (overall accuracy, mean correct RT, the conflict effect, and the three conditions), and one object per trial. The CSV repeats that snapshot in params_json on every row.

Shared columns are task_id, mode, params_json, trial_index, block, stimulus, condition, response, accuracy, rt_ms, timestamp, onset_perf_ms, and response_perf_ms. Flanker columns after those are trial_in_block, target_dir, flanker_dir, fixation_ms, and timed_out. condition is congruent, incongruent, or neutral. stimulus is the five-character array. accuracy is 1 or 0. The saved payload keeps the same summary and the trial rows, including mode. File names start with flanker_conflict_. The page does not log orientation turns.
