Eriksen Flanker

Report the direction of the center arrow. The arrows beside it may match, conflict, or be dashes. Six practice trials come before the 36-trial main block.

What it shows

Each trial shows a fixation cross, then a row of five symbols. The center symbol is < or >. On congruent trials the flankers point the same way. On incongruent trials they point the other way. On neutral trials the flankers are dashes. The summary compares accuracy and mean response time for those three conditions.

The gamified shell says correct, incorrect, or too slow after each trial. Classical practice uses a shorter word, and the classical main block does not. See Shells. This is a teaching demo, not a clinical or normed test.

Parameters

Practice
6 trials. One of each condition for each target direction, then a Fisher–Yates shuffle.
Main block
36 trials. Six of each condition for each target direction, then a Fisher–Yates shuffle.
Array
Flanker, flanker, target, flanker, flanker. Congruent copies the target. Incongruent uses the opposite arrow. Neutral uses -.
Fixation
A random duration from 400 ms through 600 ms. A plus sign. The choice is not open yet.
Choice window
1500 ms from stimulus onset. A timeout is incorrect, shows TOO SLOW, and stores an empty response time.
Feedback
400 ms, then a 350 ms blank.
Accuracy and mean time
Accuracy is correct trials divided by all trials in the block, so a timeout counts as incorrect. Mean response time uses correct trials only.

Classical presentation

The welcome and results screens have a Gamified | Classical control. The choice is stored in this browser as project-trial:mode. ?mode=classical still opens the lab shell.

Eriksen and Eriksen (1974), doi:10.3758/bf03203267, used a central target letter with flanking letters. This demo already uses arrows. Classical draws that same array as plain dark glyphs on gray, with the center arrow in the same ink as the flankers. Trial counts, the 1500 ms window, and the left/right mapping are unchanged.

Shells

The same flanker core runs in two shells. Eriksen Flanker is the gamified shell. Classical Flanker is the quiet lab shell on a mid-gray canvas. Both use one trial list: 6 practice trials and 36 main trials, with the same arrays, keys, and timings. Neither shell plays sound or keeps a score.

The gamified shell shows TOO SLOW, ✓ CORRECT, or ✕ INCORRECT after every practice trial and every main trial, with the response time or the target side underneath. Classical practice keeps a short word for the 400 ms hold only: Correct, Incorrect, or No response. It does not show the response time or that subtitle. The classical main block writes no words. The feedback line is cleared, and the 400 ms hold and 350 ms blank still run, so the time from one trial to the next does not change. The end screen is the same in both shells: main-block accuracy, mean correct response time, and the conflict effect. Practice is not part of those totals.

How to play

  • Look at the center symbol. Choose the direction it points.
  • Left pad, A, or Left Arrow means left. Right pad, L, or Right Arrow means right. A pad press and a key call the same choice.
  • A held key does not answer again. One choice is accepted while the arrows are waiting for a response.
  • Run Again starts practice over and clears the on-screen log for the new run.

Data

When the main block finishes, this browser stores one payload under the localStorage key projectTrial_flanker_v1. A later finished run replaces that payload. Nothing is uploaded. There is no Clear saved control.

Download Trial CSV writes the current run, practice and main, as a file on the device. Columns are trial, block, condition, target_dir, flanker_dir, response, correct, rt_ms, timestamp, and mode (gamified or classical). The saved payload includes the same trailing mode field. The file name is flanker_conflict_ plus a timestamp. The page does not log orientation turns.
