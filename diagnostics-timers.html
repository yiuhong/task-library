The rule on this page

These are conservative rules of thumb for a browser tab, not a lab certificate. The same thresholds are written into the JSON.

  • Pass if this tab stayed visible and, for the 16 ms and 50 ms delays, the median of observed minus requested is 8 ms or less.
  • The 0 ms delay is reported. Browsers often clamp it. That row does not fail the check on its own unless its median observed time is above 20 ms.
  • Fail if the 16 ms or the 50 ms median lateness is above 8 ms, or if the 0 ms median observed time is above 20 ms.
  • Could not run if this tab was hidden during the check. That is not a machine fail.

Each delay is requested 5 times. Pass is a check icon and the word Pass. Fail is a cross icon and the word Fail. Could not run is a dash icon and those words.

Interpretation

setTimeout is not a vertical-blank interrupt. The scored two-dimensional tasks schedule fixation, stimuli, and the gaps between trials from display frames. Spatial Go/No-Go schedules its gap and its 1200 ms window from the headset animation frame while an immersive-vr session is running, and from the page animation frame on a flat preview. This check reports how late a setTimeout callback was compared with the delay this page asked for.

Browsers often clamp a request of 0 ms. That row is shown here. It is not a fail on its own unless the median observed time is above 20 ms.

navigator.deviceMemory, when the browser sends it, is a coarse bucket, often capped. The CPU value is a hint. The storage line is a one-key probe: the page writes project-trial:device-check-probe, reads it back, and removes it. Verdicts are not stored. Trial rows are not stored here.

What this page can and cannot stand behind

  • setTimeout is not a vertical-blank interrupt. The scored two-dimensional tasks do not use it for fixation, stimuli, or the gaps between trials. Spatial Go/No-Go schedules its gap and its 1200 ms window from headset frames during immersive-vr, and from page animation frames on a flat preview.
  • The callback is not locked to the display. A background tab can delay it further. A hidden tab is not scored as a machine fail.
  • The download is a JSON file you choose to save. This site does not receive it. The check does not open a task, does not score a person, and does not ask for consent because it is not a study.
