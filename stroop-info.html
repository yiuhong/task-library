Stroop Dash

A short teaching demo of selective attention. Name the ink color and ignore the word.

What it shows

On congruent trials the word and the ink match. On incongruent trials they do not. The results screen compares mean response time on correct trials. A slower incongruent mean is the interference contrast this demo is built to show.

The score, combo, and arcade wording are for the classroom demo. They are not a clinical or normed measure.

Parameters

Trials
20. 10 congruent and 10 incongruent. No practice block.
Colors
RED #ff4b4b key R, GREEN #44ff44 key G, BLUE #4444ff key B, YELLOW #ffff44 key Y.
Congruent
Word and ink are the same color. The 10 trials cycle RED, GREEN, BLUE, YELLOW, so the counts are 3, 3, 2, and 2.
Incongruent
Word index i % 4, ink index (i + 1) % 4. That yields RED/GREEN ×3, GREEN/BLUE ×3, BLUE/YELLOW ×2, YELLOW/RED ×2. The word is never the ink color.
Order
Fisher–Yates shuffle after the lists are built.
Ready screen
400 ms. The word READY? in white.
Response window
2000 ms, then TOO SLOW. That trial is incorrect.
Between trials
Feedback stays 400 ms, the word clears, then a 300 ms blank.
Scoring
Correct trials add max(0, 1000 − rounded RT) plus combo × 100. Combo increases before that bonus, so the first correct trial is already ×1. An error or a timeout sets combo to 0 and adds nothing.
Accuracy
Correct trials divided by all trials so far, including timeouts.
Speed
Mean RT of correct trials only. Timeouts are stored but left out of the mean. On the results screen, 0 ms means that condition had no correct trial. The interference sentence is shown only when both conditions have at least one correct trial.

How to play

  • Tap the R, G, B, or Y pad, or press that key. Pads call the same response path as the keyboard.
  • Keys are not case-sensitive. A held key does not answer the next trial. Ctrl, Cmd, and Alt chords are ignored, so find and reload still work.
  • One response is accepted per trial, and only while the colored word is on screen.
  • A tap is counted once. A click that follows the same press within 750 ms is ignored.

Data

Each run is saved in this browser under the localStorage key project-trial:stroop. Refreshing, leaving, or closing the tab keeps it. Play again appends another session and does not resume an unfinished one. Nothing is uploaded. The browser keeps the newest 100 sessions for this task.

Download CSV writes every saved session as a file on the device. Columns are trialNum, type, responseKey (r, g, b, y, or timeout), rt, isCorrect, orientationType, orientationAngle, orientationAt, orientationTMs, orientationReason, record, sessionId, startedAt, endedAt, and complete. Trial rows use record = trial. The file name is stroop_dash_data_ plus a timestamp.

Portrait and landscape both run. The page never locks the device direction. Each trial row stores the orientation at the response. Extra CSV rows with record = orientation are the session turns: start, each change, and end, with ISO time (orientationAt) and orientationTMs (milliseconds from performance.now()). A short note appears if you rotate, and the task keeps going. The results screen reports the starting orientation and how many turns were logged.

Clear saved removes project-trial:stroop from this browser. It asks for a second click. The on-screen summary stays until you leave the results screen. Download before you clear if you still want the file. Play again returns to the welcome screen, and the max combo resets.
