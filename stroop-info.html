Stroop Dash

A short teaching demo of selective attention. Name the ink color and ignore the word.

What it shows

On congruent trials the word and the ink match. On incongruent trials they do not. The results screen compares mean response time on correct trials. A slower incongruent mean is the interference contrast this demo is built to show.

The results screen can still show the gamified score. A running score is not shown during a trial. This is not a clinical or normed measure.

Parameters

Trials
20. 10 congruent and 10 incongruent. The gamified shell has no practice block.
Colors
RED #ff4b4b key R, GREEN #44ff44 key G, BLUE #4444ff key B, YELLOW #ffff44 key Y.
Congruent
Word and ink are the same color. The 10 trials cycle RED, GREEN, BLUE, YELLOW, so the counts are 3, 3, 2, and 2.
Incongruent
Word index i % 4, ink index (i + 1) % 4. That yields RED/GREEN ×3, GREEN/BLUE ×3, BLUE/YELLOW ×2, YELLOW/RED ×2. The word is never the ink color.
Order
Fisher–Yates shuffle after the lists are built.
Ready screen
400 ms. Gamified shows READY?. Classical shows a plus sign for the same 400 ms.
Response window
2000 ms, then TOO SLOW. That trial is incorrect.
Between trials
Feedback stays 400 ms, the word clears, then a 300 ms blank.
Scoring
Correct trials add max(0, 1000 − rounded RT) plus combo × 100. Combo increases before that bonus, so the first correct trial is already ×1. An error or a timeout sets combo to 0 and adds nothing.
Accuracy
Correct trials divided by all trials so far, including timeouts.
Speed
Mean RT of correct trials only. Timeouts are stored but left out of the mean. On the results screen, 0 ms means that condition had no correct trial. The interference sentence is shown only when both conditions have at least one correct trial.

Shells

The same Stroop core runs in two shells. The welcome and results screens have a Gamified | Classical control. The last choice is stored in this browser as project-trial:mode. A visit with no mode in the address uses that choice, or gamified if nothing is stored. ?mode=classical still opens the lab shell and stores that choice.

Classical Stroop follows Stroop (1935), doi:10.1037/h0054651: a colored color-word, centered, name the ink, ignore the word. The field is mid-gray. Response keys are plain R G B Y. It uses the same main block: 20 trials, the same colors, keys, and timings, without score, combo, shake, or reward sounds. During a trial it does not show accuracy or response time. Fixation is a plus sign for the same 400 ms the gamified shell uses for READY?.

Classical starts with 8 practice trials, 4 congruent and 4 incongruent, built the same way as the main list (one of each color, then the four word/ink pairs). Practice shows Correct, Incorrect, or No response for the 400 ms hold. The main block shows no words after a trial. The 400 ms hold and 300 ms blank still run. Practice is saved with block = practice and is left out of the end screen. That screen reports accuracy and mean response time for the 20 main trials, plus the congruent and incongruent means. The scoring row above describes the gamified shell only.

How to play

  • Tap the R, G, B, or Y pad, or press that key. Pads call the same response path as the keyboard.
  • Keys are not case-sensitive. A held key does not answer the next trial. Ctrl, Cmd, and Alt chords are ignored, so find and reload still work.
  • One response is accepted per trial, and only while the colored word is on screen.
  • A tap is counted once. A click that follows the same press within 750 ms is ignored.

Methods note

Both shells share the 20-trial main list, the colors, the keys, and the timings. Classical adds the 8 practice trials. After the response is stored, the gamified shell shows PERFECT!, OOF!, or TOO SLOW! for the 400 ms hold. Classical practice shows Correct, Incorrect, or No response. Classical main shows no word. The hold and the 300 ms blank still run. Live score, combo, accuracy, and mean RT stay off in both shells. The word is not set on fire, and the page is not recolored by the combo, so that cue does not sit on the next trial. For a main block without the word, use classical.

The results buttons are the shared export on For researchers. Fixation (400 ms), the 2000 ms window, the 400 ms hold, and the 300 ms blank are scheduled from display frames. Each intended duration is the nearest whole frame at the refresh rate the page estimates. rt_ms is the unrounded time from the frame that shows the colored word, including a timeout. The mean on the screen still uses correct trials only. params.timing is the frame scheduler that ran. If the tab was hidden or frames were delayed, the page says so and timing_flag is set. The frame stamp is when the page asks for the paint. It is earlier than the pixels and earlier than the light. Practice rows are marked practice. Nothing is uploaded. Browser timing limits are on For researchers and the device check.

Data

Each run is saved in this browser under the localStorage key project-trial:stroop. Refreshing, leaving, or closing the tab keeps it. Play again appends another session and does not resume an unfinished one. Nothing is uploaded. The browser keeps the newest 100 sessions for this task.

On the results screen, Download CSV and Download JSON write this run, practice and main. The JSON schema is project-trial.export.v1. The task id is stroop. Shared columns come first. Task columns are trial_in_block, word, ink, correct_key, orientation_type, orientation_angle, orientation_at, orientation_t_ms, and orientation_reason. condition is congruent or incongruent. response is r, g, b, y, or timeout. accuracy is 1 or 0. File names start with stroop_dash_. The welcome button Saved sessions CSV is the older log of saved sessions, including orientation turns. Clear saved still removes project-trial:stroop.

Portrait and landscape both run. The page never locks the device direction. Each trial row stores the orientation at the response. Extra CSV rows with record = orientation are the session turns: start, each change, and end, with ISO time (orientationAt) and orientationTMs (milliseconds from performance.now()). A short note appears if you rotate, and the task keeps going. The results screen reports the starting orientation and how many turns were logged.

Clear saved removes project-trial:stroop from this browser. It asks for a second click. The on-screen summary stays until you leave the results screen. Download before you clear if you still want the file. Play again returns to the welcome screen, and the max combo resets.
